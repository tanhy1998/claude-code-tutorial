# Starting point: advanced Power BI, Claude Code consumer but not author

The learner is advanced in Power BI, knows the PBIP format with TMDL and PBIR, and is familiar with git but doesn't use it daily. In Claude Code they've used skills, but CLAUDE.md and MCP were always set up by asking Claude to do it. They have never written config by hand.

**Evidence**: self-reported in the first session (2026-10-15).

**Implications**: skip all Power BI fundamentals. Every lesson should have them write the config artifact by hand and understand its load/scope behaviour, not just get it installed. Expect gaps in the git workflow (branching, `.gitignore`, line endings) and teach them in passing where PBIP needs them.
