Claude Code for Power BI projects

From hand-written CLAUDE.md to a team-ready PBIP plugin.

Mission Speed up my Power BI work and give my team an AI-assisted PBIP workflow they can clone. Prove it on a dummy project, then take it to work. MISSION.md

The order follows the docs' advice to build your setup over time: start with always-on context, then add on-demand knowledge, then automation and enforcement, then packaging. Each lesson adds one piece to the same lab\ repo. The capstone puts them all together.
