CLAUDE.md & memory

One page. Source: code.claude.com/docs/en/memory (checked 2026-10-15, Claude Code v2.1.300).

Scopes

User~\.claude\CLAUDE.md (+ ~\.claude\rules\)You, every projectPersonal style and preferences

Load rules

  1. At launch: every CLAUDE.md and CLAUDE.local.md in the working directory and all ancestors.
  2. Concatenated, never overridden. Order: managed → user → root … → working directory. In each directory, .local comes after CLAUDE.md. The nearest file is read last.
  3. Subdirectory CLAUDE.md files load on demand, when Claude reads or edits a file in that subdirectory.
  4. After /compact: the project-root CLAUDE.md is re-read from disk. Nested files reload on demand.
  5. Conflicting instructions → Claude may pick one arbitrarily. Remove conflicts.
  6. It's context, not enforcement. Hard guarantees need a PreToolUse hook.

AGENTS.md

Read natively since v2.1.277. Default is either/or, not both (docs):

Repo hasClaude loads
AGENTS.md onlyAGENTS.md
AGENTS.md + CLAUDE.md (or CLAUDE.local.md) here or aboveCLAUDE.md only. AGENTS.md is ignored.
CLAUDE.md containing @AGENTS.mdBoth. AGENTS.md comes in through the import.
  • ~/.claude/CLAUDE.md, managed CLAUDE.md and .claude/rules/ don't block AGENTS.md.
  • To load both without an import, set /config → Project instructions → claude-md-and-agents-md.
  • Not read: AGENTS.local.md, AGENTS.override.md, .agents/.
  • Windows/team: use @AGENTS.md import, not a symlink.

Writing checklist

  • Under 200 lines per file. Files over 4 MiB are skipped.
  • Concrete and checkable: "UTF-8 without BOM", not "careful with encoding".
  • Headers and bullets, not dense paragraphs.
  • Add a line when Claude makes the same mistake twice, or review catches something it should have known.
  • Procedures → skill. Part-of-repo guidance → path-scoped rule. Must-never-happen → hook.

## PBIP rules
- Semantic model = TMDL in `*.SemanticModel/definition/`. Report = PBIR JSON in `*.Report/definition/`.
- NEVER edit: `definition.pbir`, `report.json`, `mobileState.json`,
  `semanticModelDiagramLayout.json`, `diagramLayout.json`.
- NEVER read or edit `.pbi/` (`cache.abf`, `localSettings.json`).
- UTF-8 without BOM. CRLF line endings.
- Before editing: ask me to Save in Desktop. After: tell me to click "Apply external changes".
- If `.pbi/unappliedChanges.json` exists, stop and ask me to apply pending changes first.
