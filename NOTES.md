# Teaching notes

## Learner preferences
- Sessions up to ~1 hour. Hands-on in their own terminal is the default.
- Windows 11, PowerShell is the main shell. Claude Code CLI v2.1.302 (checked 2026-10-18; was v2.1.300 on 2026-10-15). Python 3.13 and git 2.51 available. Sessions start in **auto mode** (built-in default since v2.1.283).
- Hand-written config got mangled by some markdown editor (pbir.md, Lesson 2). Always tell them to use Notepad or VS Code, and add a "verify what loaded" step after every config edit.
- Advanced Power BI. Don't explain DAX, modeling, TMDL, or PBIR basics. Explain the Claude Code side in depth.
- So far they've had Claude do the config for them ("prompt claude to install for me"). Lessons should make them **write config by hand** first, then let Claude help.
